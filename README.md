# Personal portfolio landing for https://anasayyazdev.com

Next.js static marketing site with Framer Motion — structure inspired by the multidex-clone layout, project data from Cloud Sol landing work.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Build and deploy to Vercel (or any Node host):

```bash
npm run build
npm start
```

Point the `anasayyazdev.com` domain at the deployment when ready.
